# @b2bcorpcom/ai

Anthropic Claude API 클라이언트 + 프롬프트 모듈.

각 워커가 부르는 평가/정제/요약 프롬프트는 모두 여기서 export한다. 워커에 프롬프트 문자열을 직접 박지 않는다 — 프롬프트 수정이 한 곳에서 일어나야 회귀 검증이 가능.

**핵심 프롬프트 (개발 예정):**
- `scorer.ts` — "기초만 깔끔히 해놓은 곳" 판별 (PLAN.md D13).
- `normalizer.ts` — 회사소개·보도자료·블로그 글에서 핵심 정보 5축 추출.
- `embedder.ts` — 청크별 임베딩 입력 생성.
